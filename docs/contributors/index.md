# Contributors

Work by individual contributors that we find useful and link to. It is **not** produced by Renaissance Labs; each page says who made it.

- [Validating RL environments](marianna13-rl-validation.md), by Marianna13: a validation protocol and a list of validated datasets.
- [Mid-training data and context extension](marianna13-midtraining-data.md), by Marianna13: building a mid-training mixture and extending a 9B model to 64K and 128K context.
- [The 8-pixel frog](nicolas-8-pixel-frog.md), by Nicolas Jonason: an RL run where a picture-drawing model learned to fool its judge, with the full PDF report.
