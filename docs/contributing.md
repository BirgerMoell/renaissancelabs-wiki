# Contributing

Pages are Markdown files in the `docs/` folder of the repository.

1. **Collaborators** with write access commit to `main`, or open a pull request for a second opinion.
2. **Everyone else** forks the repo and opens a pull request. A maintainer reviews it before it is published.
3. Use the **edit** icon at the top of any page to jump to its source on GitHub.

## What must never go in this repo

This site is public. Do not commit credentials, cluster addresses or access details, unpublished partner material, or personal data. Anything private belongs in the private wiki repository.
